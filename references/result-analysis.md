# 结果分析

`analyze.py` 读取实验目录中的 `config.yaml`、`metrics.csv`、`metrics.json` 和默认验证评估 `eval.json`。它提供基础汇总与作图，未实现多种子分组统计或实验协议自动校验。

| 命令 | 输出 |
|---|---|
| `summary --exp-root <目录>` | CSV、Markdown 表与说明 |
| `curves --exp-root <目录> --metric val_loss` | 训练曲线 PNG 与图注 |
| `sweep --exp-root <目录> --x loss.alpha --y best_val_mse` | 单参数曲线 PNG 与图注 |
| `sweep --exp-root <目录> --x model.depth --x2 model.hidden_dim --y best_val_mse` | 双参数曲面或散点 PNG 与图注 |

`--mode max` 适用于越大越好的指标。指标读取优先级为 `metrics.json`、`eval.json`、CSV 末行；三者可能分别代表最佳 checkpoint、指定权重评估和最后一轮，比较前核对来源，不混为“最优结果”。

## 分析前检查

- 只纳入协议一致的实验：相同数据与划分、指标定义、选模规则和可比预算。缺失、失败及非有限值单独记录，不能当作零或默默剔除。
- 按方法、配置、数据条件分组，再对随机种子聚合。报告每次结果、n、均值及标准差或置信区间；当前脚本不做该聚合，多种子结果需扩展脚本。
- 保留原始精度，显示时再四舍五入。图注描述实测范围，不从单次最优值推出显著性或因果机制。
- 重复横坐标不能直接连成趋势线。二维曲面的插值不是实测数据，也不能独自证明交互作用；稀疏或退化网格用散点或热图。

## 任务图表

输入规模、噪声强度或计算预算扫描需先确定协议：固定权重在不同条件下评估，还是每个条件重新训练。前者应编写评估扫描并保存条件与权重标识，不能默认对每个条件重新训练。

重建、掩码或注意力图用任务脚本，固定样本索引、预处理和显示范围；同时展示有代表性的失败样本。记录样本选择规则，避免只挑有利例子。

投稿图按最终版面检查字号、单位、线型和色盲可辨性；标量图优先 PDF/SVG，位图按投稿要求导出。模板 PNG 为 200 dpi 预览，不等同于投稿成图。

图注写清数据划分、指标及方向、各线/点含义、重复次数和误差条定义。自动生成的文字只能作初稿。机理解释标为假设，直到有相应对照实验支持。保留作图命令与原始数据，确保表图可重建。
