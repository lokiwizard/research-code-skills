# 结果分析与可视化

把实验产物变成论文能直接用的表格、曲线、消融图与文字。核心工具是
`scripts/analyze.py`（读 `experiments/*/` 下的 config.yaml / metrics.csv /
metrics.json / eval.json）。

## 三类产出与对应命令

| 论文里的角色 | analyze.py 子命令 | 说明 |
|---|---|---|
| 主结果对比表 | `summary` | 跨实验最终指标汇总（Markdown + CSV） |
| 训练曲线 | `curves --metric <列名>` | 指标 vs epoch，多实验叠加 |
| 消融曲线 | `sweep --x <超参> --y <指标>` | 指标随单个超参变化 |
| 3D 消融曲面 | `sweep --x <超参> --x2 <超参> --y <指标>` | 两个超参的交互（如 α 与 L） |

每个命令都会在 `results/` 下同时输出图片（PNG, 200dpi）和一段 `.md` 的论文风格 caption，
caption 里的数字是真实算出来的，文字是初稿，按论文语气微调即可。

## "X vs Y" 类图怎么出

这类图（PSNR vs SNR、LPIPS vs token budget、准确率 vs 数据量……）本质都是
"某指标随某个**可配置的量**变化"。做法：

1. 把那个量做成配置项（如 `dataset.snr`、`model.token_budget`）。
2. 用 `make_ablation.py --mode oat` 对它生成一组配置并各训练一次。
3. `analyze.py sweep --x dataset.snr --y best_val_psnr` 即得曲线。

3D 曲面同理，给两个 `--x/--x2`。

## 重建/样本对比类可视化

`analyze.py` 处理标量指标；图像重建对比、注意力图、分割掩码叠加等**图像级**可视化
通常要写一小段任务专属脚本（放进项目 `scripts/`）。建议：

- 固定一组样本索引，所有方法用同样的输入，便于横向对比。
- 网格排版：行=样本，列=方法（GT / baseline / ours / …），每格标注关键指标。
- 用 `matplotlib` 的 `subplots` + `imshow`，关掉坐标轴，留窄间距。
- 保存为矢量（PDF/SVG）或 ≥300dpi PNG，方便投稿。

## 论文图表审美规范

- **字号**：图中字号接近正文（投稿后缩放仍可读）；统一字体。
- **配色**：用区分度高且色盲友好的离散色（如 tab10）；序列数据用 viridis 类连续色。
- **线条**：不同方法用不同 marker + 线型，黑白打印也能区分。
- **一致性**：同一篇论文里坐标轴名、单位、方法名、配色保持一致。
- **信息密度**：一图说清一件事；图例不挡数据；坐标轴从合适的范围开始。
- **可复现**：作图脚本和数据一起留档，图能一键重画。

## caption 与分析文字写法

- caption 先陈述"这是什么图"（坐标轴、每条线代表什么），再点出"读者该看到什么"。
- 分析文字要**解释为什么**，不只是复述数字：哪个结果支撑了方法有效、哪个暴露了局限、
  哪个异常需要排查。把规律说成可写进论文的论断（并注意不要过度夸大）。
- 区分"观察到的事实"与"我的解读"，结论要有数据支撑。
